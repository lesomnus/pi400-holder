# Pi 400 PCB와 볼트·너트 치수 정리

- 기준: **P16 최종 출력 설계와 함께 배포된 나사형 손잡이**
- 정리일: 2026-10-15
- 단위: **모두 mm**
- 실측값, 명목값, 출력 설계값을 구분한 문서입니다. CAD와 STL은 변경하지 않았습니다.

> **출력 설계값은 STL에 반영된 치수입니다. 이미 적용된 끼움 여유가 포함되어 있으므로, 그대로 재현할 때 같은 여유를 다시 더하지 않습니다. 출력 후 실제 치수나 슬라이서 보정값을 뜻하지는 않습니다.**

## 1. PCB 구멍 위치와 직경

### 좌표 기준

- PCB 뒷면에서 **GPIO와 A홀이 왼쪽, 포트가 위쪽**인 방향입니다.
- **PCB 왼쪽 아래 모서리**를 원점 `(0, 0)`으로 둡니다.
- X는 오른쪽, Y는 위쪽 방향입니다.
- 좌표는 **구멍 중심** 기준입니다.

| 구멍 | X | Y | PCB 구멍 직경 Ø | 값의 성격 |
|---|---:|---:|---:|---|
| A | 3.75 | 8 | 2.95 | 사용자 실측 그대로 |
| B | 83.2 | 25 | 4.95 | 사용자 실측 그대로 |
| C | 154 | 25 | 4.90 | 사용자 실측 그대로 |
| D | 223 | 8 | 2.90 | 사용자 실측 그대로 |

| PCB 외형 항목 | 치수 | 값의 성격 |
|---|---:|---|
| 가로 | 227 | 사용자 실측 |
| 세로 | 50 | 사용자 실측 |
| 기판 자체 두께 | 1.25 | 사용자 실측 |

**A부터 D까지의 구멍 좌표와 직경에는 추가 여유를 넣지 않았습니다.**

### PCB 구멍과 출력물 구멍의 차이

위 구멍 표는 **PCB 참고 모델의 치수**입니다. PCB 자체를 출력하는 것은 아닙니다.

- 손잡이는 **A 구멍 중심 `(3.75, 8)`**을 그대로 사용합니다.
- 실제 PCB의 A 구멍은 **Ø2.95**입니다.
- 출력하는 손잡이의 볼트 관통홀은 **Ø2.8**입니다. PCB 구멍 직경과 동일하지 않습니다.
- B·C·D 구멍에 대응하는 체결 부품은 현재 출력 설계에 없습니다.

## 2. PCB 아래 두 홈과 받침 위치

| 항목 | 치수 | 기준 |
|---|---:|---|
| PCB 홈 폭 | 9.9 | 사용자 실측 |
| PCB 홈 깊이 | 3.1 | 사용자 실측 |
| 두 홈의 가까운 변 사이 | 173 | 최신 실측으로 확정 |
| 앞쪽 홈 중심 X | 22.05 | PCB 길이 227 및 좌우 대칭 기준 계산 |
| 뒤쪽 홈 중심 X | 204.95 | PCB 길이 227 및 좌우 대칭 기준 계산 |
| 홈 중심 간격 | 182.9 | `173 + 9.9` |
| PCB 양끝에서 각 홈 시작까지 | 각각 17.1 | 좌우 대칭 조건에서 계산 |

최초에 알려준 끝단 거리 17로 계산하면 홈 사이 거리는 다음과 같습니다.

```text
227 - 2 × (17 + 9.9) = 173.2
```

최신 실측 **173**을 적용하면서 각 받침이 중앙 쪽으로 **0.1씩** 이동했습니다. P14 시험편에서 길이 맞춤을 확인했고, P16에도 같은 위치를 유지했습니다.

### 베이스에서의 받침 위치

앞뒤 베이스가 맞닿는 접합면 기준입니다.

| 항목 | 거리 |
|---|---:|
| 접합면 → 앞 돌기 중심 | 77.95 |
| 접합면 → 뒤 돌기 중심 | 104.95 |
| 앞뒤 돌기 중심 간격 | 182.9 |
| 최대 폭 10인 두 돌기의 가까운 변 사이 | 172.9 |

**PCB 홈 사이 173과 출력 돌기 사이 172.9는 다른 치수입니다.** PCB 홈 폭은 9.9이고 출력 돌기 최대 폭은 요청에 따라 10으로 설정되어 있기 때문입니다.

## 3. 볼트·너트 자체 치수

| 항목 | 치수 | 값의 성격 |
|---|---:|---|
| 볼트 규격 | M2.5 | 사용 규격 |
| 볼트 나사부 지름 | 명목 Ø2.5 | 규격 기준값 |
| 볼트 머리 지름 | Ø4.3 | 사용자 실측 |
| 볼트 머리 높이 | 2.36 | 사용자 실측 |
| 너트 대변 거리 | 5.0 | 설계상 명목값, 사용자 실측 미확인 |
| 너트 두께 | 2.0 | 설계상 명목값, 사용자 실측 미확인 |
| 실제 사용 볼트 길이 | 미확인 | 도면의 10은 미리보기용 예시 |

**대변 거리**는 육각형의 마주 보는 **평평한 면 사이 거리**입니다. 꼭짓점 사이 지름이 아닙니다.

## 4. 출력물에 반영된 볼트 구멍과 너트 홈

| 항목 | 베이스 또는 연결판의 출력 설계값 | 손잡이의 출력 설계값 |
|---|---:|---:|
| 볼트 관통홀 지름 | Ø2.8 | Ø2.8 |
| 볼트 머리 홈 지름 | Ø4.5 | Ø4.5 |
| 볼트 머리 홈 깊이 | **2.7** | **1.5** |
| 육각 너트 홈 대변 거리 | **5.1** | **5.1** |
| 육각 너트 홈 깊이 | **1.8** | **1.8** |

- 베이스 체결에서는 **머리 홈이 베이스 바닥에**, **너트 홈이 위쪽 연결판에** 있습니다.
- 볼트는 바닥에서 위로 삽입합니다.
- 손잡이의 머리 홈과 너트 홈은 손잡이 양쪽에 있습니다.
- 너트 홈 대변 5.1은 출력 후 잘 맞는다고 확인한 설계값입니다.

### 이미 적용된 치수 차이

아래 차이는 **전체 지름 또는 대변 치수의 차이**입니다. 한쪽당 여유가 아닙니다.

| 항목 | 기준값 | 출력 설계값 | 이미 적용된 차이 |
|---|---:|---:|---:|
| 볼트 나사부 → 관통홀 | 명목 Ø2.5 | Ø2.8 | 지름 +0.3 |
| 볼트 머리 → 머리 홈 | 실측 Ø4.3 | Ø4.5 | 지름 +0.2 |
| 너트 → 육각 홈 | 명목 대변 5.0 | 대변 5.1 | 대변 +0.1 |

이 출력 설계값으로 재현할 때는 위 차이를 다시 더하지 않습니다. 너트의 차이는 실제 너트 실측값이 아닌 **명목값과의 비교**입니다.

### 베이스와 연결판 치수

| 항목 | 출력 설계값 |
|---|---:|
| 베이스 바닥 두께 | 5.4 |
| 연결판 두께 | 4.0 |
| 연결판 길이 × 폭 | 18 × 10 |
| 연결판 볼트 중심 간격 | 10.0 |
| 베이스 머리 홈 위 잔여 두께 | 2.7 |

P16의 베이스 머리 홈 깊이는 **4.2에서 1.5 줄인 2.7**입니다. 베이스 바닥 두께 5.4는 유지했습니다.

실측 머리 높이 2.36 기준으로 볼트 머리는 베이스 바닥보다 **0.34 안쪽**에 들어가는 명목 형상입니다. 실제 출력 후 돌출 여부를 확인해야 합니다.

손잡이 머리 홈은 깊이 1.5이므로 같은 머리가 완전히 들어가는 구조는 아닙니다. 너트 홈 깊이 1.8도 명목 너트 두께 2.0보다 얕습니다.

같은 볼트를 사용하면 P16은 이전 깊이 4.2 설계보다 너트 쪽 돌출 길이가 **1.5 줄어듭니다.** 충분히 체결되는지 확인하세요.

## 5. PCB가 닿는 출력부 치수

| 항목 | PCB 기준 | 출력 설계값 | 차이 또는 구분 |
|---|---:|---:|---|
| 손잡이 PCB 접촉부 간격 | 두께 1.25 | **1.5** | 총 +0.25 |
| 손잡이 내부 비접촉 공간 | 두께 1.25 | **2.5** | 실제 접촉부와 구분 |
| 베이스 수직 날개 사이 간격 | 두께 1.25 | **1.25** | 추가 여유 없음 |
| 아래 홈 / 중앙 돌기 폭 | 홈 폭 9.9 | **최대 10.0** | 요청 반영, +0.1 |

### 날개와 중앙 돌기

| 항목 | 출력 설계값 |
|---|---:|
| 날개 두께 | 1.2 |
| 날개 폭, PCB 길이 방향 | 10 |
| 날개 높이, 받침 바닥 윗면 기준 | 12.1 |
| 날개 기울기, 수직 기준 | 0° |
| 중앙 돌기 최대 폭, PCB 길이 방향 | 10 |
| 중앙 돌기 두께, PCB 두께 방향 | 0.6 |
| 중앙 돌기 높이 | 3.1 |
| 중앙 돌기 맨 위 평평한 부분의 폭 | 8 |

돌기 맨 위 평면이 8인 것은 양끝에 기존 1mm 빗면이 있기 때문입니다. 최대 폭 10과 구분해야 하며, 이를 출력 수축으로 해석하면 안 됩니다.

## 6. 수치 사용 시 주의사항

1. **PCB 실측값과 출력물의 구멍 치수는 서로 다릅니다.** 특히 PCB A 구멍 Ø2.95와 손잡이 관통홀 Ø2.8을 구분하세요.
2. 출력 설계값에는 적용했던 여유가 이미 포함되어 있습니다. 같은 여유를 중복해서 더하지 않습니다.
3. 명목값은 실제 부품 실측값이 아닙니다. 너트 대변 5.0과 두께 2.0, 미리보기 볼트 길이 10을 사용자 실측으로 취급하지 않습니다.
4. 출력 후 실제 치수는 프린터와 슬라이서 설정 등에 따라 달라질 수 있습니다. 이 문서는 출력 후 실측 치수표가 아닙니다.
5. 날개 간격 1.25에는 추가 여유가 없고, 돌기 최대 폭 10은 PCB 홈 실측 9.9보다 큽니다. 맞춤 확인 없이 억지로 조립하지 않습니다.
