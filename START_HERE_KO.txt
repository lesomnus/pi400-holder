반복 연결 구조
거치대 한 장은 273 x 216.8 x 22.5mm입니다. 양쪽 가장자리를 늘리지 않았습니다.
다음 장은 폭 방향으로 222.4mm 떨어진 위치에 놓습니다.
판 사이 5.6mm 공간은 06번 연결부 가운데 기둥이 전체 길이에 걸쳐 채웁니다.
연결부 양쪽 사각 돌기 4개를 판의 홈에 넣고 볼트로 고정합니다.
연결부 최고점은 바닥에서 10mm로 케이스 받침 높이와 같습니다.
두 판의 가장자리가 직접 맞닿는 구조는 아니며, 그 사이를 연결부가 채우는 구조입니다.
두 장 전체 폭은 439.2mm, 세 장은 661.6mm입니다.
케이스 사이 간격은 모든 위치에서 27mm로 유지합니다.
거치대가 N장이면 좌우 연결부는 N-1개 사용합니다.
사각 돌기와 홈은 12 x 8 x 2mm이며 추가 여유 0mm입니다.
케이스와 거치대의 길이 방향 벽 간격은 247mm, 추가 여유 0mm입니다.
옆 지지 날개 6개는 중심에서 바깥쪽으로 각각 0.25mm 이동했습니다.
날개 사이 폭은 29.1mm(닫힌 케이스 28.6mm + 양쪽 합계 0.5mm), 날개 두께는 3mm입니다.
중앙 받침과 날개 사이 0.25mm 틈은 받침 윗면(바닥 기준 10mm)까지만 메웠습니다.
받침 위쪽의 날개 위치와 케이스 끼움 간격은 그대로입니다.
손잡이 반대쪽 양각은 0.6 -> 1.6mm, 손잡이 쪽 둥근 돌출부는 0.2 -> 1.2mm입니다.
환기구에 들어가는 단면과 둥근 끝 모양은 유지하고 돌출 깊이만 1mm 늘렸습니다.

볼트 조립 (접합부 1곳 기준)
M2.5 볼트 4개, 육각 너트 4개. 와셔 없음. 바닥에서 위쪽으로 삽입합니다.
관통 구멍 Ø2.5mm, 바닥 머리 홈 Ø4.5mm / 깊이 2.7mm.
연결부 윗면 너트 홈: 육각 대변 5.1mm / 깊이 1.8mm. 추가 여유 모두 0mm.
사용자가 잘 맞는다고 확인한 M2.5 시험편의 치수를 그대로 반영했습니다.
밑면 볼트 머리 -> 거치대 -> 연결부 -> 윗면 육각 홈의 너트 순서입니다.
머리 높이 2.7mm이면 밑면과 일치합니다. M2.5x8 사용 시 끝은 연결부 윗면보다 0.7mm 올라옵니다.
연결부 사각 돌기가 이동/회전을 제한하고, 볼트는 연결부가 위로 빠지는 것을 잡습니다.

타이 방향은 케이스의 좁은 면과 평행하며, 타이 폭 2.5~3.6mm 기준입니다.
